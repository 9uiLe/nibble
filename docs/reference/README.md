# 外部仕様の参照

外部の公開仕様と研究は、製品の制約や評価方法を判断する資料です。nibbleの機能は[製品仕様](../product-specification.md)、構成は[アーキテクチャ](../architecture/README.md)に定義します。

| 資料 | 用途 |
| --- | --- |
| [OSの境界](platform.md) | 呼び出し、共有、キーボード、クリップボードの能力と権限 |
| [保存と検索](storage.md) | SQLite、WAL、原文、日本語検索の根拠 |
| [利用者評価](usability.md) | 操作時間、誤選択、理解の評価と研究の適用限界 |
| [保護と公開](security.md) | データの露出、配布申告、ライセンス |
| [UIの一次資料](../design/evidence.md) | R番号の指針、確認範囲、製品への適用限界 |

各資料の確認日と適用範囲を読み、API・OS・提出要件の判断時に原典を確認してください。外部指針の記載だけでは、製品の実動作や審査結果を保証できません。
