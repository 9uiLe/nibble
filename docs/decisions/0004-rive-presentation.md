# コピー・保存を伝える説明イラスト

説明イラストは、元の文章を残したまま複製をnibbleへ保存する関係を伝える。製品情報S05では導入文の直後に二つのモバイル画面を置き、キーボード案内S10では入力先へ本文を渡す操作を補う。文章だけでも意味と読み上げが成立するようにする。

## 表現と配置の理由

文章選択、コピーメニュー、複製の移動、保存、完了を一周期で示す。元の文章が消えないことと保存先に項目が増えることを描く。装飾だけの動きにせず、視線の順序と内容の移動に対応させる。

自動ループは途中から読んだ場合にも説明へ戻れるために使う。再生ボタンを必要とせず、同じ画面内の文章を読んでいる間も意味を追える構成とする。静止図は負荷と注意の分散を抑えられる一方、複製/移動の順序を別の表現で示す必要がある。理解度と読書への干渉は利用者評価の対象であり、自動再生の効果を実証済みとはしない。

## 制作・表示・画面の分担

| 所有者 | 契約 |
| --- | --- |
| RML | 図形、時間、状態遷移、Data Bindingの意味。編集の正本 |
| 生成物とmanifest | アプリへ同梱するrivと、入力/出力・名前/型の対応 |
| RivePresentation | File再利用、契約検査、表示ごとのSession、Canvasの停止・再描画 |
| ホスト | Sessionの寿命、配色・可視性・再生方針、説明文、失敗表示と再試行 |

名前・型・初期値・状態遷移は[アセット手順](../../app/Animations/README.md)、汎用APIと所有は[Package契約](../../app/Packages/RivePresentation/README.md)を正本とする。

## 状態と寿命

ホストはtaskからロードとSession生成をawaitし、取消済みの結果を表示しない。同じ表示の再描画でSessionを作り直さず、別表示は独立したSessionを持つ。

nibbleは[表示固定方針](../design/decisions/0002-fixed-interface.md)に従いmotionAllowedをtrueにする。これは時間を進める演出方針であり、不可視・View離脱・非active時のフレーム停止とは別である。可視性をpausedへ渡し、停止中の配色変更は描画更新番号で反映する。同じSessionの再生位置を保持して復帰する。

activeや演出完了を実際の保存・コピー成功に使わない。図は触れない説明として扱い、隣接Textが意味と読み上げを担う。読込失敗でも説明を読め、再試行できるようにする。

## 採用理由と再利用

RMLから生成できる図と型付きData Bindingにより、制作の時間表現とSwiftUIの画面状態を分ける。RivePresentationは製品パスに依存せず、他製品はアセット・ホスト方針・lock・runtime同梱を用意して利用する。iOSの旧runtime APIとは接続を混在させない。

## 保守と受け入れ

制作ソース・生成物・manifestを一緒に更新し、構造検査と実バイナリ接続、画像、複数周期、停止/復帰、配色、失敗回復を確認する。CLIのviewport指定は実際の出力寸法で確かめ、CLIの処理時間をiOSの描画性能へ転用しない。

依存は互換性・ライセンス・toolchain・runtime容量を確認して固定する。描画負荷は[性能手順](../performance-verification.md)、実行導線は[MVP手順](../mvp.md)に従う。設計値や生成成功を実画面の性能達成と扱わない。
