## 基本操作と自動検査

Releaseの標準UI driver `scripts/check-mvp-ui.py` が成功した。新規作成を閉じて下書きから再開し、保存、日本語検索、編集、コピー、ピン留め、削除、取り消し、下書き破棄を操作した。削除一覧では検索0件の案内、語句による絞り込み、復元と一覧への復帰まで確認した。

| 契約 | 観測 |
| --- | --- |
| 標準ナビゲーション | 「すべて」「ピン留め」「検索」の3つの標準タブをAX情報で確認 |
| 新規作成の配置 | 検索ボタンの上、末尾側の端位置の差は8 pt以内。表示領域は70×70 pt |
| 検索入力 | 検索タブの選択でキーボードが開き、新規作成が隠れる。検索確定でキーボードが閉じ、新規作成が戻る |
| タブ間の分離 | 検索0件でも「すべて」に項目が残る。「ピン留め」に検索欄は表示されない |
| 原文の保持 | 作成後、編集後、下書き破棄後、削除一覧からの復元後の本文をUTF-8完全一致で照合 |
| 項目の同一性 | 編集、削除取り消し、削除一覧からの復元で同じUUIDを保持 |
| 製品テスト | Releaseで43件成功。パラメータ展開後44実行、失敗・skipなし |
| 共通検査 | Nix全5 check成功。Python85テスト、Swift30ソースの規約検査を含む |

製品テストにはタブごとの検索語・取得上限の分離と、共有保存層のピン解除・削除を再取得で反映する検査を含む。画像や録画の一致でモデルの状態を代替せず、モデルAPIの完了時点とUI操作を別々に検査する。

## 確認範囲の制約

- 画像・動画はローカル原本を確認した。PRへの添付とブラウザーでの閲覧確認は未実施。`review.json` の添付先と閲覧欄は未記入であり、証跡の公開完了を示さない。
- 日本語はペースト入力を使った。IME変換、VoiceOver、Reduce Motion切り替え、小画面、横向き、iPad、RTL、実機はこのソースで再検証していない。
- 起動・検索・タブ切り替え・描画・メモリの定量比較は未実施。driverの待機を含む録画時間を性能改善の根拠にしない。
- 共有拡張、保存形式、依存バージョンは変更していない。今回のUI runはSafariとの共有・ペーストを再評価していない。
