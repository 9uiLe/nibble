画面タイトルを標準ナビゲーションバーの左側に置き、全幅のリストをその直下から表示する構成を検証した。採用するAPIと画面の責務は[製品設計](decisions/0002-mvp-app.md#タブと片手操作)を参照する。

## 確認結果

| 対象 | 観測 |
| --- | --- |
| タイトル | 一覧と設定の見出しがバー左側に収まり、省略されない。Debugで一覧をスクロールしても左側の位置を保持 |
| リスト | 横幅を使った行と区分を表示。設定を最大Dynamic Typeでスクロールし、削除一覧とAboutまで到達 |
| 標準ナビゲーション | Aboutの戻る操作、削除一覧の閉じる操作、検索入力・終了が成功。検索入力中はシステムが上部バーを隠す |
| 日常操作 | Releaseで下書き作成・再開・保存、日本語検索、編集、コピー、ピン、削除・Undo、下書き破棄、削除一覧の検索・復元が成功 |
| 同一性と設定 | コピーのUTF-8完全一致、編集・復元のUUID一致、左右配置と再起動後の保持を確認 |
| 外観と通知 | Debugでライト・ダーク、最大文字、コントラスト強調、コピー通知と2.3秒後の消去、URLによる編集開始と編集中の保護を確認 |

外観設定は実行前後でlight / large / contrast disabledに一致した。`large-light.png`は外観切り替え直後で白いタイトルが残るが、設定復元後の`restored.png`とReleaseのライト画像では黒いタイトルを確認した。標準toolbarのタイトルと左右選択ラベルは最大Dynamic Typeでも本文のようには拡大しない。

Debug実行後の過去10分について、NibbleのScopedAnimationカテゴリと`Unhandled ViewTaskStore`を含むログは空配列だった。観測した経路に限る結果である。

## 最終評価に使用しない実行

- `20260916T235721Z-library-settings-display-db552a`は最大文字の設定でAboutが画面外にあり停止した。補足driverを実際のスクロール位置に対応させた。この実行の`inlineLarge`タイトルはスクロール時に中央へ変化したため、採用した固定位置の評価には使わない。
- `20260917T000035Z-library-settings-display-c3a713`は操作に成功したが、画像の目視でタイトルの省略を発見した。文字本来の幅を保つ修正と幅の検査を加え、上記の別runで再確認した。

## 確認範囲の限界

この変更は画面配置を対象とし、製品単体テストは再実行していない。44件の成功は[一覧と設定の検証](library-settings-validation.md)に記載したソースに対する結果である。速度・描画・メモリの定量比較は未実施で、性能改善は主張しない。

PRへの媒体添付・ブラウザー閲覧、IME変換、VoiceOver、Reduce Motion切り替え、RTL、小画面、横向き、iPad、実機、共有拡張の操作はこのソースで未評価。TestFlightの配信状態と実機動作は配布担当者が確認する。
