# 文言設計

[F09](foundations.md#f09-文言とデータ)の語彙を、実際に起きる処理へ対応させる。実装上の名称ではなく、対象、状態、次の行動を伝える。文字列の一覧を固定仕様へ増やすのではなく、意味を実画面と照合する。

| 場面 | 意味と表現 | 避ける混同 |
| --- | --- | --- |
| 本体の一覧 | 「プロンプトを検索」。全保存済みのタイトル・本文を検索する | ピン内だけの検索、読込中と0件 |
| 本体の入力 | 「タイトル」「本文」。×はキャンセル、チェックは保存。変更があれば「変更を破棄しますか？」で確認する | 閉じた入力が作業中一覧に残るという案内 |
| 本体の管理 | 「タイトルを変更」は名前だけ、「削除」は対象名を確認して一覧から除く。直後に「元に戻す」 | 本文編集や完全消去 |
| 旧構成の保存済み一覧 | 「名前や本文から探す」「すべて」「ピン留め」。選択した集合の検索であることを伝える | 全体検索とピン内検索、読込中と0件 |
| 旧構成の途中作業 | 「作業中」「作成中」「編集中」「差し替え中」。再開して保存・利用・破棄を選ぶ | 保存済み文章や、既にコピーした結果 |
| 旧エディターの終了 | 「保存」は利用対象へ反映、「閉じる」は最新作業を保持 | 閉じるを変更破棄と受け取ること |
| 変換中 | 文字の変換を確定してから完成文や終了操作へ進む | 無効なボタンだけで理由を隠すこと |
| ひな型の指定 | 編集画面の「差し替えを使う」を必要な文章だけオンにする。既定オフなら印も原文のまま使う | {{…}}を含むだけで勝手にひな型にすること |
| 準備 | ひな型は変えず、今回の相手・用件を入れる | 原文の編集、再利用カード保存の強制 |
| 全文確認 | 「この内容を使います」「この内容をコピー」 | 行要約を全文とすること、Markdown描画結果を出力とすること |
| コピー完了 | コピーしたので入力先へ戻ってペーストする | 自動貼付・送信済み |
| 片付け失敗 | コピーは完了、作業の片付けができなかったので自動再実行しない | コピー失敗としてもう一度作用させること |
| 独立保存 | 現在入力を別の文章へ保存し、元の文章・作業を残す | 元の文章の更新・復元、ひな型との自動連動 |
| 完成文の保存 | 必要な人だけ別の固定文として保存。名前は任意で、相手・用件の識別に使える | 中断回復の必須条件、ひな型の最新版への追随 |
| ごみ箱 | 「ごみ箱へ移す」「元に戻す」「文章を戻す」。対象を識別し、作業中の入力は別に残る | 完全消去、関連作業の破棄 |
| Keyboard | ピン留め固定文の最大50件。全文確認して明示挿入、他は本体検索・コピー | 全件検索、差し替え、コピーやFull Accessが必須という案内 |
| 失敗 | 失敗した処理、保持しているもの、修正・再読込・保存などの続行方法 | 技術名だけ、実際に使えない回復、未完了の成功表示 |

旧構成の案内にある外部リンクはプライバシーポリシーとサポートとして示す。端末内保存、OSのpasteboardとバックアップ、利用者が外部リンクを開く通信を分けて説明する。理解度は[G10](audit.md#g10-説明と全体負担)で実際の結果に対応させて評価する。
