# 日本語UIの文言設計

nibbleは、よく使う文章やURLを端末に保存し、コピーやキーボード入力で再利用するアプリである。文言は、利用者が対象を選び、操作後の結果を予測し、失敗しても入力や保存済みの内容を取り違えずに作業を続けられるように設計する。

本体は保存・検索・編集・整理、共有拡張は他のアプリからの取り込み、nibbleキーボードは入力先での選択・全文確認・挿入を担う。三つの入口で同じデータと操作名を使い、入口ごとに異なる権限と終了方法を説明する。

## この設計書の読み方

語彙・文体・表記の共通規則は[文言とデータの原則（F09）](foundations.md#f09-文言とデータ)に定める。本書はその原則を操作の流れに沿って具体的な文言へ対応させる。Fは共通原則、Sは画面、Cは部品、Rは外部根拠、Gは評価課題の識別子であり、[UI設計の入口](README.md)から各台帳を参照できる。

各表は画面に表示する文言、読み上げ用のラベル、エラー文を組み立てる句を含む。同じ節で重複する文言は一度掲載する。`／`は同じ場面で使う複数の文言の区切り、`\n`は改行、`{項目名}`などの波括弧は実行時の値を表す。波括弧自体は画面に表示しない。正確な文字列と分岐は各節の実装リンクで確認する。

設計理由は採用する表現の根拠であり、理解度の測定結果ではない。表示と操作の観測、未確認の条件は[証跡手順](../review-evidence.md)に従うrun、利用者が意味を理解できるかという問いは[評価課題（G11）](audit.md#g11-c--操作と文言)に置く。

## 本体で項目を探して使う

保存済みの項目は再利用する内容、下書きは編集を再開する内容である。一覧・検索・削除済みの集合名を明示し、0件の説明はその集合でできる次の操作につなげる。行の読み上げには対象名を添え、同じ画面にある編集・コピー・復元を区別する。

### 現在地と検索対象

作業画面は製品名と設定への入口を示し、検索欄は調べる対象を伝える。一覧と検索は同じ画面で扱う。削除した項目の検索は、通常の保存済み項目の検索から独立している。

実装：[AppRootView.swift](../../app/Nibble/Navigation/AppRootView.swift)。S01・S02・S06・C01・C12・C39。

| 文言 | 役割と設計理由 |
| --- | --- |
| `nibble` | 一覧と検索を扱う作業画面の製品名を示す。 |
| `設定` | 配置の設定、復元、利用案内の入口を示す。 |
| `新規作成 ／ 選択中 ／ 検索語を消去 ／ キーボードを閉じる` | 下部の作成操作、現在地、上部検索欄の消去と入力終了の読み上げ名を定める。 |
| `タイトルや本文を検索` | 名前だけでなく本文も検索対象であると伝える。 |
| `削除した項目` | 復元または完全削除する対象の集合を示す。 |
| `閉じる` | 削除一覧を閉じて設定へ戻る。編集画面の終了とは文脈で区別する。 |
| `削除した項目を検索` | この検索欄が削除済みの集合だけを扱うと伝える。 |

### 集合・空状態・回復の入口

一覧は保存状態と取得状態を別々に示す。空状態の説明、再試行ボタン、完全削除の確認は、それぞれ対象と操作結果を持つ。

実装：[LibraryScreen.swift](../../app/Nibble/Library/LibraryScreen.swift)。S01〜S03・S06・C05・C07〜C09・C13〜C17・C38。

| 文言 | 役割と設計理由 |
| --- | --- |
| `新規作成` | 空状態でも同じ下部ボタンから作成へ進める。 |
| `完全に削除しますか？` | 回復できない削除の実行前に意思を確認する。 |
| `完全に削除` | 確認ダイアログで確定する操作を明示する。 |
| `「{項目名}」と、この項目の下書きを完全に削除します。元に戻せません。` | 項目名、関連下書き、元に戻せない結果をまとめて確認する。 |
| `読み込みを再開` | 中断した読み込みを同じ条件で実行する入口を示す。 |
| `さらに表示` | 続きの取得を利用者が開始できるようにする。 |
| `下書き` | 編集途中の内容を保存済み項目から区分する。 |
| `下書き、{下書き名}` | 下書きであることと名前を一緒に読み上げる。 |
| `編集中の項目` | 保存済みとは異なる、編集を続ける集合を示す。 |
| `保存すると、コピーやキーボード入力に使えます。` | 下書きと利用可能な保存済み項目の違いを一覧末尾で説明する。 |
| `編集を再開します` | タップの結果がコピーではなく編集の再開であると伝える。 |
| `下書きを再開` | 最新1件の編集へ戻る操作を、保存済みの利用と区別する。 |
| `ほか{件数}件` | 最新以外の下書きがあることを示し、全下書きの一覧へ移る。読み上げでは全件数と「下書きをすべて見る」を伝える。 |
| `コピー回数順` | 本体でコピーした回数による順序であり、編集やキーボード入力の回数ではないと伝える。 |
| `下書きをすべて見る` | 一覧に出ていない下書きも探せる入口を示す。 |
| `削除した項目は自動で消えません。復元すると、一覧からまた使えます。` | 削除後の保存期間と、復元後の利用先を説明する。 |
| `{表示対象}を読み込み中 ／ 読み込み中` | 取得中の対象を示し、取得前を0件と誤認させない。 |
| `一覧を再読み込み` | 保存データの取得をやり直す操作名にする。 |
| `回数と日時を記録し直す` | コピー本文ではなく、回数と日時の記録を再実行すると伝える。 |
| `もう一度復元する` | 失敗した復元の再試行であると伝える。 |
| `閉じる` | 案内を閉じる操作を示す。保存済みデータを変更する意味を持たせない。 |
| `削除した項目` | 復元・完全削除の対象を示す。 |
| `ピン留めした項目 ／ 保存した項目 ／ 検索結果` | 表示している集合を、保存状態や検索条件に合わせて示す。 |
| `見つかりませんでした ／ 別の言葉や、短い言葉で検索してください。` | 検索語を修正できるよう、短い語や別の語を提案する。 |
| `削除した項目はありません ／ 削除した項目はここに表示されます。復元すると、一覧からまた使えます。` | 削除した項目の置き場所と復元先を説明する。 |
| `下書きはありません ／ 編集画面で「閉じる」を押すと、入力した内容が下書きに残ります。ここから編集を再開できます。` | 下書きが生まれる編集の終了方法と、再開する場所を説明する。 |
| `ピン留めした項目はありません ／ 項目の「その他」からピン留めできます。` | ピン留めの入口を、画面にある「その他」の名称で案内する。 |
| `保存した項目はありません ／ よく使う文章やURLを保存すると、\nいつでもコピーして使えます。` | 保存できる対象と、保存後にできるコピーを説明する。 |
| `すべてを見る` | ピン留めなどの限定した集合から、すべての項目へ戻る。 |

### 対象ごとの操作

コピー、編集、整理はそれぞれ独立した操作である。可視メニュー・スワイプ・読み上げで同じ操作名を使う。

実装：[SnippetRow.swift](../../app/Nibble/Library/SnippetRow.swift)。S01・S02・S06・C06・C10・C11・C37。

| 文言 | 役割と設計理由 |
| --- | --- |
| `{項目名}をコピー` | コピー対象を名前付きで読み上げる。 |
| `{項目名}を復元` | 復元対象を名前付きで読み上げる。 |
| `{項目名}のその他の操作` | 対象に従属するメニューだと伝える。 |
| `ピン留め、{項目名}` | ピン留めの状態と対象名を一緒に伝える。 |
| `30日以上コピーしていません、最後にコピーした日 {日付}` | 本体での最終コピー日を読み上げ、利用全般の計測と区別する。 |
| `編集します` | 項目をタップした結果を伝える。 |
| `完全に削除` | 復元不能な削除を通常の削除と区別する。 |
| `削除` | 復元できる削除済み状態へ移す操作を示す。 |
| `ピン留めを解除 ／ ピン留め` | 現在のピン状態に応じて、実行する操作を示す。 |
| `復元` | 削除した項目を利用可能な一覧へ戻す。 |
| `編集` | 保存済みの項目を編集する入口を示す。 |

### コピー履歴の補足

表示対象は、本体で記録した最終コピーから720時間以上経過した項目である。閲覧・編集・キーボードの入力回数を測った表現にはしない。

実装：[SnippetRowContent.swift](../../app/Nibble/Library/SnippetRowContent.swift)。S01・S02・C06。

| 文言 | 役割と設計理由 |
| --- | --- |
| `30日以上コピーしていません` | 計測する操作と経過期間を明示する。 |
| `最後のコピー {最終コピー日}` | 経過期間を判断する元のコピー日を示す。 |

### 名前のない下書き

下書き名はタイトル、本文先頭の順に求める。どちらも表示名に使えないときにも、編集途中の内容だと識別できる名前を用意する。

実装：[SnippetPresentation.swift](../../app/Shared/Interface/SnippetPresentation.swift)。S01・C07。

| 文言 | 役割と設計理由 |
| --- | --- |
| `新しい下書き` | 表示内容が空でも、下書きの再開対象であると伝える。 |

## 本体の操作結果と回復

コピーは本文をクリップボードへ渡す処理と、回数・日時を保存する処理からなる。本文を渡せた後で記録に失敗した場合、本文は利用できる。結果文と再試行ボタンはこの二つを区別する。削除・復元・完全削除も、実際に完了した処理に対応する結果を表示する。

### 成功した処理と失敗した処理

失敗の見出しには処理名を含める。本文は利用者が使える内容と次の行動を示し、再試行は画面にあるボタンへ対応させる。

実装：[LibraryPresentation.swift](../../app/Nibble/Library/LibraryPresentation.swift)。S01・S02・S06・C17〜C19。

| 文言 | 役割と設計理由 |
| --- | --- |
| `コピー済みですが、回数と日時を記録できませんでした` | 本文のコピー成功と、利用記録の失敗を同時に伝える。 |
| `本文は貼り付けて使えます。下のボタンで、コピー回数と最後にコピーした日時の記録だけをやり直せます。\n` | 本文が利用可能なことと、再試行で記録だけを更新することを説明する。 |
| `通知を更新できませんでした` | 通知の更新に失敗したことを示し、データ操作の失敗と区別する。 |
| `一覧を読み込めませんでした` | 項目がないのではなく、取得に失敗したと伝える。 |
| `「一覧を再読み込み」を押してください。` | 一覧にある再取得ボタンへ誘導する。 |
| `編集を始められませんでした` | 編集画面を開く前の失敗を示す。 |
| `コピーしました` | クリップボードへの書き込みが完了したことを短く伝える。 |
| `コピーできませんでした` | 本文のコピー自体が完了しなかったことを示す。 |
| `本文は貼り付けて使えます。項目が完全に削除されたため、コピー回数と日時は記録できません。「閉じる」でこの案内を閉じてください。` | 本文の利用は可能だが、完全削除済みの対象へは記録できないと説明する。 |
| `ピン留めを変更できませんでした` | ピン状態の更新に失敗したことを示す。 |
| `削除しました` | 復元できる削除が完了したと伝える。 |
| `削除できませんでした` | 削除が完了しなかったと伝える。 |
| `元に戻しました` | 直前に削除した項目の復元が完了したと伝える。 |
| `復元できませんでした` | 復元が完了しなかったと伝える。 |
| `「一覧を再読み込み」を押してください。 ／ 「もう一度復元する」を押してください。` | 対象消失には再取得、それ以外には復元の再試行を案内する。 |
| `完全に削除しました` | 回復不能な削除が完了したと伝える。 |
| `完全に削除できませんでした` | 完全削除が完了しなかったと伝える。 |
| `「一覧を再読み込み」を押してください。 ／ この案内を閉じて、もう一度操作してください。` | 対象消失には再取得、それ以外には案内を閉じて再操作する手順を示す。 |
| `nibbleを最新バージョンに更新してから、もう一度操作してください。` | データ形式を扱えるバージョンへの更新を案内する。 |
| `保存データを読み書きできませんでした。` | 保存先の読み書きに問題があると伝え、技術的な生ログを表示しない。 |

### 削除直後の取り消し

削除の通知は対象名と復元操作を同じ領域に置く。通知の期限後は、設定の削除一覧から復元する。

実装：[LibraryNotice.swift](../../app/Nibble/Library/LibraryNotice.swift)。S01・S02・S06・C18・C19。

| 文言 | 役割と設計理由 |
| --- | --- |
| `元に戻す` | 直前の削除を取り消す入口を短い操作名で示す。 |
| `{対象名}を復元します` | 復元する対象名を読み上げる。名前がない場合は「項目」を使う。 |

## 文章を保存し編集を終える

保存済み項目の件数上限は設けない。本文の差し替え印は利用直前に値を指定すると伝え、原文が変更されないことを明示する。Proを公開するまでは購入を促さない。公開時の価格はStoreKitの商品情報を表示し、固定文字列へ転記しない。

本体と共有拡張は共通の編集画面を使う。「保存」は一覧やキーボードで使う内容の確定、「閉じる」は編集の中断、「下書きを破棄」は編集途中の内容の除去を意味する。終了処理の成功を待って画面を閉じ、失敗時には入力と回復操作を同じ画面に残す。

### 入力条件と終了操作

任意・必須は入力中も参照できるラベルで伝える。保存と中断の違いは画面下部で短く説明し、長さの条件と下書きが残らない例外は入力中も開ける補足シートに置く。

実装：[SnippetEditor.swift](../../app/Shared/Editing/SnippetEditor.swift)。S03・S07・C20〜C32。

| 文言 | 役割と設計理由 |
| --- | --- |
| `タイトル（任意）` | 常設ラベルと読み上げの両方で、入力中もタイトルが任意だと伝える。 |
| `例：お礼のメール` | タイトル欄に入れる内容の例を示す。 |
| `本文` | 保存・コピー・挿入する内容の入力欄を、表示と読み上げで同じ名前にする。 |
| `変数を追加 ／ 既存の変数を再利用 ／ 新しい変数を作成` | 差し替え印の追加入口と、既存名を使うか新しい名前を作るかの選択を示す。印は本文のカーソル位置に追加し、選択中の文字を置き換える。無効な選択位置では本文を変えず、位置を選び直す案内を出す。 |
| `本文の入力位置が変わりました。閉じて位置を選び直してください。` | 保存済みの本文を別の位置で変更しないため、シートを閉じて入力位置を決め直す操作を示す。 |

| `閉じる ／ 確定せず閉じる ／ すべての値を入力すると使えます` | シートの終了、読み上げ上の取消、未入力で確定できない理由を区別する。 |
| `変数はPro ／ 変数は準備中` | 機能の利用条件に応じ、編集できる本文と変数追加の可否を区別する。 |
| `本文の末尾にペースト` | ペーストの挿入先が本文末尾であると読み上げる。 |
| `末尾にペースト` | ペーストボタンの作用を、視覚でも確認できるようにする。 |
| `本文を入力すると保存できます。空白や改行だけでは保存できません。` | 保存ボタンが使えない理由と、必要な入力を説明する。 |
| `保存したい文章やURLを入力。Markdownも使えます。` | 本文欄に入力できる対象を具体的に示す。 |
| `入力と保存について` | 長さの条件と保存・中断の詳細を読む入口を文章と末尾の矢印で示す。 |
| `入力 ／ プレビュー` | 原文の編集と、Markdown記号を隠した見た目の確認を切り替える。 |

## キーボードで入力する

保存済み項目の主領域には「入力」、右端には「全文」と示す。全文確認と入力はフルアクセスなしで利用できる。コピーとピン留めの変更には許可が必要であり、許可前の操作では設定方法を案内する。

### 保存した本文を入力する流れの図解

実装：[KeyboardIllustration.swift](../../app/Nibble/Presentation/KeyboardIllustration.swift)。S10・C49。

| 文言 | 役割と設計理由 |
| --- | --- |
| `切り替える → 項目をタップ → 本文を入力` | キーボードの切替、行の主領域、挿入の順序を示す。 |
| `保存した文章はそのまま残ります。` | 入力しても保存済み本文が失われないことを図とともに伝える。読み上げは直前の説明へまとめる。 |

| `説明アニメーションを再読み込み` | 説明文を残したまま、図だけの読込失敗から回復する。 |

図中の「お礼」「ありがとう！」「連絡先」は架空の例で、保存データや入力先を読み取らない。結果文はKeyboardと同じ「本文を送りました」とし、入力先での保存完了を意味しない。

## 表示するデータと文言の境界

製品名は`nibble`を使い、非アクティブ時に本文を覆う面にも同じ名前を表示する。キーボードの平常時の下部領域には操作のない製品名を置かない。`nibble://library`は一覧、`nibble://new`は新規作成を開く。URLの意味と受付条件は[製品仕様・要件](../product-specification.md)に従う。

利用者が入力したタイトルと本文はアプリの固定文言とは別のデータである。本文先頭から作る表示名、プレビュー、検索用の値を原文へ逆反映しない。日付・ページ番号・対象名は実行時に求め、読み上げも画面と同じ対象を指す。

iOSが生成する共有先・編集メニュー・日付の表記はOSが所有する。同梱ライセンスは原文のまま提供する。予期しないエラーの生の技術文は利用者向けの説明に使わず、その画面で失敗した処理と実行できる回復方法を表示する。
