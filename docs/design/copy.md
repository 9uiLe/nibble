# アプリ内の文言台帳

F09の方針を本体・共有・キーボードへ適用した採用理由を記す。文言の実値はリンク先のソース、方針は[共通原則](foundations.md#f09-文言とデータ)、表示・理解確認の実施範囲は[検証記録](../copy-validation.md)が正本である。

比較元はIssue #35着手時の `5f1f9fc`。コード内の日本語リテラルを全件照合し、同じ文言が別の場面にある場合も残す。表の `\(...)` は対象名や日時などの動的値、`\n` は改行。条件で切り替わる文言は同じ行に併記する。利用者のタイトル・本文、OS生成の共有先・編集メニュー・日付表示、テストデータ、同梱ライセンスは改稿しない。

「維持」はその文脈で意味と操作が一致するという設計判断であり、利用者テスト合格を意味しない。読み上げの専用文字列も同じ表で確認する。

## 製品名・URLと動的な本文

- `nibble`：製品名、非アクティブ時の覆い、キーボードの待機表示として維持する（S08・C40、S09・C47）。
- `nibble://library` / `nibble://new`：既存のURL契約を維持する。用途ラベルだけを「一覧を開く」「新しく作る」とする（S05・C36）。
- タイトル未入力時の本文先頭、タイトル・本文の全文、プレビュー、更新日時、ページ番号は動的な表示として維持する。読み上げも同じ対象を指し、原文の書き換えは行わない（C06・C07・C21・C22・C46）。
- 共有provider等から返る予期しないエラーは生の技術文を表示せず、その操作の失敗と再操作を案内する（C17・C30・C42・C47）。
