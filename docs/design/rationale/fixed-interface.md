# 表示設定の固定

nibbleは本体・共有拡張・キーボードの文字、太字設定、独自配色のcontrast、独自演出を一定にし、ライト/ダークには追従する。表示の階層と操作配置を製品として揃える判断であり、OS設定へ追従する一般指針とは区別する。

## 設計値と実装境界

Dynamic Typeはlarge、文字の太さの環境はregular、contrastはnormalに固定する。View内の見出し等の太さは情報階層として使う。独自演出はReduce Motionによらず同じ表現とし、RiveへmotionAllowed=trueを渡す。

共通modifierとUIKit traitの入口は[NibbleInterface](../../../app/Shared/Interface/NibbleInterface.swift)に置く。別windowの通知、sheet、extensionにも適用し、画面ごとに独自の設定追従を加えない。寸法は内容に応じて伸縮・折返しを許し、省略した本文には全文への経路を持つ。

## OSが所有する表示と操作

標準keyboard、編集メニュー、共有先、system sheet内部などOS所有部分の内部表現はOSへ委ねる。既存のOS操作は共通modifierの設定値によって変更しない。

## 理由と制約

一定の文字階層と配置で、画面を移動しても操作位置と情報量を把握できるようにする。個別の文字拡大には対応しないため、狭幅でも折返しと全文表示で内容への到達を保つ。この判断による読みやすさの制約は利用者評価で確認し、個別画面の場当たり的な追従で解消しない。

## 検証と見直し

全画面の適用漏れは標準設定と最大文字＋高contrastを比較する。modifier単体はhostedテストで小さい文字入力も固定されることを確認する。値比較Viewの環境更新試験と製品入口の固定試験は別の保証である。

ライト/ダーク、狭幅、長文、OS所有表示を[製品の検証手順](../../ios-verification.md)で評価する。主要操作への到達や可読性が満たせない場合は共通方針として見直す。
