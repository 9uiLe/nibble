# 操作・識別・回復

## 判断

本体は検索と保存済み一覧を一つにし、行の選択を内容確認・差し替えへ、編集・ピン・ごみ箱を可視の管理メニューへ割り当てる。作成はtoolbarに独立した文字付き操作を置く。作業中は別区分で示し、直近2件と全作業への入口を持つ。

## 目的と代替

一覧から即座にコピーする構成は固定文の操作を減らせるが、類似文・長文・差し替え結果の確認が弱くなる。今回の構成は、対象の識別から文字どおりの全文確認、明示コピーへつなぐ。短文の反復利用に確認の負担が増えるため、同条件の一連の利用で評価する。

編集を行の既定操作にすると、利用するつもりで作業を開く負担が増える。管理操作を見えるメニューへ分け、長押し・スワイプの知識を必須にしない。作業を保存済み一覧へ混ぜる代替は、途中入力を使う内容と混同するため採用しない。

## 回復と全体負担

閉じるは作業を保持し、明示保存だけが利用対象を変える。失敗・競合では入力を残し、独立保存へ接続する。整理は確認付きごみ箱移動と復元を使い、関連作業を連鎖削除しない。完全消去のUIを持たないため、保持データの意味と容量は別に説明・評価する。

作業と保存済みを分けることで再開入口が増える。下書き多数時の発見、誤選択、一覧への圧迫を評価し、画面内のタップ数だけで採用効果を断定しない。契約は[製品仕様](../../product-specification.md)、評価は[G01〜G09](../audit.md)に定める。
