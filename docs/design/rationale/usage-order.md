# 並び順とピン留め

## 判断

本体の保存済み一覧はピン優先、更新日時降順、UUID昇順とする。検索は選択中のすべて／ピン留めへ適用する。使用回数・最終利用日時を収集して順位を変える方式は採用しない。

## 使用の意味

コピー、OSのペースト、Keyboardの挿入呼出し、ホストでの受理、送信は異なる。コピーを実際の文章利用の全体と同一視せず、コピー回数を利用の正本へしない。読取専用Keyboardは利用履歴を書き込まない。

## 代替と全体負担

利用回数順は頻用対象を自動で上へ出す候補だが、本体コピーとKeyboard挿入の観測差、外部作用後の記録失敗、順位の変化を利用者が追う負担を追加する。今回は利用者のピン選択と検索を使う。

ピン留めにも選定と整理の負担がある。Keyboardは固定文の最大50件だけを提供し、全件探索は本体へ置く。多数のピン、未掲載対象、よく使わない類似文章での発見を評価し、ピンがあることだけで探索の目的達成とはしない。

## 見直し条件

同条件での一連の利用で、手動のピン整理や未掲載の発見が継続的な負担になった場合に、分類・順序・取得方式を比較する。履歴の収集を前提へ戻す前に、利用者の負担と保存・権限・プライバシー・保守の費用を示す。[G03・G10](../audit.md)で評価する。
