# 操作結果と失敗の通知

## 判断

保存・ピン・ごみ箱移動・復元は操作した一覧に結果を表示し、閉じる操作を持つ。ごみ箱移動の結果は対象を識別して「元に戻す」へ接続する。コピーは内容確認画面に完了と、入力先へ戻ってペーストする次の操作を示す。

専用window、通知のための演出、業務とは別の自動再実行を持たない。通知期間やアニメーションの終了を、保存・コピー・挿入の完了条件にしない。

## 通知の寿命

表示は現在の操作結果に対応し、新しい結果や明示的に閉じる操作で更新する。期限後の復元へ依存せず、ごみ箱からも回復できる。結果の表示で検索入力・本文・主要操作が隠れないことをsafe areaと実画面で確認する。

## 成功と失敗

成功は対象処理の確定後だけ表示する。コピー呼出しが戻った後、準備作業の片付けに失敗しても「コピー失敗」としない。コピー完了と片付け失敗を併記し、自動再コピーしない。ホストへの挿入呼出しと、ホストの実際の全文受理も区別する。

失敗は理由、保持している内容、続行方法を処理した場所へ残す。再読込、保存再試行、独立保存、破棄は別操作として示し、再試行で別の副作用を起こさない。

## 評価

連続操作、結果表示中の検索・文字入力、長い対象名、狭幅、画面の終了・再表示、片付け失敗、ごみ箱からの復元を確認する。本文の読み上げや通知への不要な露出も避ける。問いは[G05〜G08](../audit.md)、操作契約は[製品仕様](../../product-specification.md#非同期操作の完了契約)を参照する。
