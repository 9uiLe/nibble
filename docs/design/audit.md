# UIの評価課題

採用仕様は[S画面](screens.md)・[C部品](components.md)が正本である。この台帳は実操作と利用者理解を確認する問いを定める。項目の存在を実施済みとせず、対象source・OS・構成・データ・操作・結果を持つrunで判断する。

## 評価対象

本体、共有取り込み、任意の固定文Keyboardを対象とする。最低対応iOS 26.0への適合、iOS 26.5 Simulatorでの成立、利用者の理解、性能は異なる確認である。実機は製品受入へ含めない。[検証範囲](../testing.md#検証範囲と制約)と対象runを照合する。

### G01 準備から必要な場所で使うまで

C01・C02・C05・C10。新規作成と他アプリからの共有それぞれで、保存→後から検索→全文確認→コピー→入力先でOSペーストまで進む。短文・長文、日本語・Unicode、似た名前・無題を含め、入力先で実際の全文を照合する。

### G02 編集と準備の中断回復

C04・C07〜C09。日本語変換・訂正、閉じる、背景化、再起動、保存失敗の後に意図した内容で使えるか。差し替え値を再利用カードへ保存しなくても再開できるか。保持できた範囲と未確定入力の限界を区別する。

### G03 大量保存からの発見

C02・C03・C06・C14。少量と大量、短い日本語検索、長文、類似文章で正しい対象を選べるか。ピン留め・検索条件の意味、Keyboardの最大50件と本体全体の違いを理解できるか。未掲載の対象を本体検索・コピー経由で使えるか。

### G04 文字どおりの完成文と読みやすさ

C07・C09〜C11。Markdown記号、空白・改行・Unicode、差し替えオフの`{{…}}`を含む本文と出力が一致するか。差し替え指定だけの変更を保持・再開・保存できるか。長文の末尾、狭幅、Dynamic Type、ライト／ダーク、OSキーボード表示で読めるか。全プレビューによる負担と誤選択防止の効果を両方評価する。

### G05 外部作用・取消・重複防止

C10・C13・C14。値不足・変換中・取消では作用ゼロ、明示操作と連打で一度、片付け失敗・再表示・再試行で自動重複なしを確認する。コピー呼出し、ペースト、挿入呼出し、ホスト受理、送信を別に記録する。

### G06 入力先変更と利用不可

C14・C15。確認後のA→B、A→B→A、選択変更、Keyboard非表示・再表示で旧確認を使えないか。Full Access拒否、未設定、secure入力やホスト拒否で、状況を理解して本体コピーの経路を続けられるか。独立試作の成功を製品SQLiteの成立へ流用しない。

### G07 保存失敗・競合と独立保存

C08・C09・C13。保存先の一時失敗、元の版の更新・ごみ箱移動、同じ作業の別画面更新で現在入力が残るか。再試行と独立保存の対象を理解でき、元の文章と作業を無言で上書きしないか。

### G08 削除と回復

C05・C12・C13。類似文章と連続移動で対象を理解し、通知からの取り消し、ごみ箱検索と復元を使えるか。本文・ピンと関連作業を保持し、復元以外の意図しない確定保存を起こさないか。完全消去できると誤解しないか。

### G09 完成文を残す判断

C09・C11。毎回変わる値にはカード保存を要求せず、同じ相手・用件の反復利用だけに任意保存を使えるか。由来名を自動追随と誤解せず、カード増殖と古い相手の取り違えを防げるか。独立救出は通常の新規文章で、由来の関係を保証しない。

### G10 説明と全体負担

C01・C13・C15。初見でコピーから貼付まで進めるか、必要な人がOS設定を経てKeyboardを使えるか。文言から保持・保存・コピー・挿入・破棄・復元の結果を説明できるか。Aのコピー中心とBの任意Keyboardを同じ利用条件で比較し、準備・設定・往復・判断・誤操作・資源消費を含める。タップ数や画面の好みだけで優劣を決めない。
