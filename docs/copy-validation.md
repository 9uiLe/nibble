## 未確認の範囲

日本語話者の初見評価は参加者0名で未実施。VoiceOverの実音声、フォーカス順、読み上げ操作も未実施である。文言レビュー、ソース検査、アクセシビリティ情報の取得は、これらの代わりにはならない。

## 利用者による理解確認

初見の日本語話者に事前の操作説明をせず、同じ検証用データで結果と次の行動を本人の言葉で説明してもらう。参加者のnibble・iOS利用経験、端末、表示条件、提示文言、回答、誤解を記録する。文言を修正した場合は、再確認の条件と回答も残す。

| 提示する場面 | 確認する意味 |
| --- | --- |
| 編集後の保存／閉じる | 一覧・キーボードで使う内容の確定と、編集を再開する下書きの保存 |
| 閉じる／下書きを破棄 | 中断と、回復できない編集内容の除去。保存済み項目への影響 |
| 削除／完全に削除 | 復元できる削除と、関連下書きを含む回復不能な削除 |
| コピー済み・記録失敗 | 本文は貼り付けて使えることと、回数・日時だけを再試行すること |
| キーボードの入力／コピー | 入力先への挿入要求とクリップボードへのコピー。入力先での反映確認 |
| フルアクセス未許可 | 入力・全文確認は利用でき、コピー・ピン留めの変更には許可が必要なこと |

VoiceOverでは同じ場面について、対象名と操作名の読み上げ、入力・失敗表示・再試行へのフォーカス順、操作後の結果を確認する。少人数の結果を全利用者へ一般化せず、G11の受入判断には参加者の回答と未確認条件を対応させる。
