## 初見の理解・読み上げの未実施条件

日本語話者の初見評価は参加者0名で未実施。エージェントによる文言レビューは、利用者の回答として数えない。VoiceOverの実音声・フォーカス順・読み上げ操作も未実施であり、ソースやAX情報でのラベル照合と区別する。

実施時には事前に操作方法を教えず、同じダミーデータで次の結果と次の行動を本人の言葉で説明してもらう。参加者のnibble/iOS利用経験、端末、表示条件、提示文言、回答、誤解、修正後の回答を残す。

| 提示する場面 | 確認する意味の違い |
| --- | --- |
| 編集後の保存／閉じる | 一覧・キーボードで使える内容と、編集を再開する下書き |
| 閉じる／下書きを破棄 | 中断と回復できない編集内容の除去、保存済みへの影響 |
| 削除／完全に削除 | 復元できる項目と関連下書きも含む回復不能な削除 |
| コピー済み・記録失敗 | 本文を貼り付けて使えることと、回数・日時だけの再試行 |
| キーボードの入力／コピー | 入力先への挿入要求とクリップボードへのコピー、入力先での反映確認 |
| フルアクセス未許可 | 入力・全文は利用可、コピー・ピン変更は許可が必要 |

少人数の結果から全利用者への改善効果を断定しない。未実施条件が残る間はIssueの理解度に関する受け入れ条件を完了にしない。
