## 最終評価に使用しない実行

- `20260917T004539Z-mvp-ui-e520be`は、標準検索を閉じても検索語が残るというdriverの前提で停止した。検索を開いて語を入力し直す手順で再確認した。
- `20260917T005239Z-library-filters-display-4a9f90`と`20260917T005441Z-library-filters-display-3270ec`では、フィルターが見えている状態でAX情報に個々のボタンが含まれず停止した。固定領域をリストから分離し、横スクロール全体の明示的なアクセシビリティグループ化を除いたソースで確認した。
- `20260917T005612Z-library-filters-display-35ab9f`は、最大文字でdriverが横へ大きくスクロールしすぎ、対象ボタン全体の表示を判定できず停止した。観測したボタン位置に合わせてスクロール量を決める補足driverで再確認した。

失敗runも保持する。途中のソースで成功したテストとUI runは、上表の最終評価と区別する。

## 確認範囲の限界

sim-useはフィルターの選択traitを`states`へ返さなかったため、選択色は画像、表示対象はUI・操作テストで確認した。VoiceOverの音声読み上げは未実施。標準Listの固定見出しにはスクロール中の背後の行が透けて見える。

Releaseでの評価であり、Debugのアニメーション診断、Reduce Motion切り替え、IME変換、RTL、小画面、横向き、iPad、実機、共有拡張の操作はこのソースで未評価。速度・描画・メモリの定量比較は行っておらず、性能改善は主張しない。

PRへの媒体添付とブラウザー閲覧は未実施。TestFlightの配信状態と実機での動作は配布担当者が確認する。
