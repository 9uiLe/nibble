# 原文の編集と作業の回復

編集は文章を育て直すための作業であり、利用する保存済み文章とは別に保持する。本体と共有取り込みが同じ`WorkspaceEditorView`、`DraftSessionModel`、`NativeDocumentField`を使う。意味と終了条件は[製品仕様](../product-specification.md#入力の保存と編集の終了)が正本である。

## 表現と責務

`UITextView`のOS標準入力をSwiftUIへ接続し、日本語の変換・訂正・選択・ペーストをOSに任せる。名前は任意、本文は原文のまま編集する。「差し替えを使う」は既定オフで、必要な文章だけ明示的にオンにする。オフなら`{{…}}`を含むコードや文章も文字どおりに使える。独自かな漢字入力やMarkdown装飾・描画切替は設けない。完成文の確認にも文字どおりの全文を使う。

これは変換した見た目と出力文字列を照合する負担を減らすための選択で、長文が読みやすいという検証結果ではない。標準文字サイズ、折返し、スクロール、選択と狭い表示での到達を実画面で確認する。

## 入力と表示の寿命

Coordinatorは最新のBindingへ入力を返し、UTF-8が異なるときだけモデルを更新する。marked text中はUIから本文を再設定しない。再同期が必要な場合は有効な選択範囲を維持し、範囲外なら本文末尾へ退避する。変換中は保存・閉じる・コピーを無効にし、変換確定を案内する。

OSが担当する選択や取り消し履歴を、View更新のたびに新規入力欄へ移し直さない。標準ペーストは現在のカーソル・選択範囲へ適用し、アプリ独自のクリップボード先読みを加えない。

## 作業の保存と確定

`WorkDraft`は新規・既存編集・準備を区別し、本文・名前・値・差し替え指定が変わるとsequenceを進める。画面のtaskはsnapshotのcheckpointをawaitする。checkpoint済みsequenceと現在sequenceの一致を、入力保持の表示に使う。

ローカルの編集回数と、読み込んだ／保持できた作業のsequenceは区別する。checkpointは後者を保存先と照合するため、古い画面で多く編集しても、別の画面が保持した入力を上書きしない。同じモデルのcheckpointは順に完了を待ち、待機中の新しい入力へ保持済みの基点だけを引き継ぐ。

「保存」は現在作業を保持したうえで利用対象へ反映し、成功後だけ閉じる。「閉じる」は最新作業の保持を待ち、保存済み文章を変えない。「作業を破棄」は確認して当該作業だけを消す。スワイプで保持を迂回して閉じない。

## 失敗と回復

保存・保持・終了の失敗は、スクロール位置によらず理由を読めるOS標準のアラートで知らせる。変換中の入力をアラートで中断せず、確定後に知らせる。「入力に戻る」で元の内容へ戻り、同じ作業で再試行できる。本文のそばにも失敗と独立保存の経路を残す。

保存先の問題では入力と画面を残して再試行する。対象の変更・削除、作業の同時更新・終了では、現在入力を独立した別文章へ保存できるようにする。独立保存は元の文章・作業を上書きせず、両方を残す。ごみ箱移動で関連作業を消さない。

同じ作業が別の画面で更新・終了された場合は、確認後にこの画面の入力だけを破棄して閉じることもできる。新しい保存済み作業を削除・上書きせず、終了済みの作業を再生成しない。通常の保存先障害を、この局所破棄の理由へ読み替えない。

独立保存の途中で失敗した場合は、同じ画面内では一つの救出用作業を再利用し、訂正後の入力で再試行できる。失敗を繰り返しても作業を増やさず、保存先の障害へエラーが変わっても独立保存の入口を残す。

中断後は「作業中」の「作成中」から独立保存用の作業を開いて再開する。元の作業も残るため、名前が同じ場合は本文を開いて確かめる。元の作業を開き直して改めて独立保存を選ぶ操作は、新しい救出作業を開始する。画面の再作成やプロセス終了をまたいで、この明示操作を前の救出と自動的に同一視する仕組みは持たない。

空白だけの本文も作業には保持するが確定保存はしない。checkpointできた後に確定が拒否されても、その作業を削除しない。全キー入力と異常終了直前の未確定入力の永続化は保証せず、成功した保持の範囲を表示する。

## 開発と検証

新規・既存編集・共有・再開で、日本語変換、訂正、カーソル移動、選択範囲へのペースト、中断・再開、保存失敗・競合を確認する。短文・長文、改行、NUL、結合文字、絵文字、狭幅と文字拡大を含める。内部値の直接設定は自然な入力の検証を代行しない。

検証の入口は[実行手順](../ios-verification.md)、UIの問いは[S03](../design/screens.md#s03-作成編集下書き再開)と[評価課題](../design/audit.md)に置く。
