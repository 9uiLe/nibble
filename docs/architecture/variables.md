# 変数の編集と利用

差し替えは、共通部分を維持しながら相手・用件だけを変える能力である。本体のOS標準入力で今回の値を用意し、文字どおりの完成文を全文確認してから使う。利用と作業回復のために、完成文を再利用カードとして保存する必要はない。

## 編集から利用まで

編集画面で「差し替えを使う」を明示的にオンにし、本文へ`{{宛名}}`のような印を記述する。既定はオフで、`{{…}}`の形だけではひな型にしない。オフなら印を含む原文のまま確認・コピー・固定文挿入できる。同名の有効な印は一つの入力欄で扱い、全箇所を同じ値で置換する。名前は前後の空白を除き、空・改行・波括弧を含むものを変数として扱わない。無効な印とその他の本文は原文として残す。

保存済み文章を選ぶと、差し替えがオフまたは有効な印がなければ全文確認、オンかつ有効な印があれば耐久的な準備作業を開始する。値が揃うまでコピーせず、揃った完成文をスクロールして確認する。値の前後空白・改行も出力に含め、名前の正規化を値へ適用しない。

「閉じる」は入力値を保持して戻り、「作業中」から再開する。今回の入力の破棄は確認後に準備作業だけを除く。ひな型の原文は変えず、取消・破棄でコピーや挿入をしない。

## 責務と状態

| 所有者 | 責務 |
| --- | --- |
| `TextCard.usesVariables`・`WorkDraft.usesVariables` | 明示した差し替え指定。既定オフで、本文から自動推論しない。作業の同一性・入力番号・永続化に含める |
| `TextTemplate` | 指定がオンの本文のUTF-8を印とliteralへ分け、必要名と完成文を導出。値の不足を失敗として返す |
| `WorkDraft.prepare` | ひな型のUUID・開始version・原文snapshotと今回の値を、独立したsequence付き作業として保持 |
| `UseSessionModel` | 値入力、checkpoint、元の版の再照合、明示コピーとcopied状態、任意の完成文保存 |
| `NativeDocumentField` | 本体で日本語入力・訂正・確定をOSへ接続 |
| `WorkspaceUseView` | 項目名、入力値、全文、保持・コピー・任意保存の意味を表示し、操作の寿命を所有 |

コピーはcheckpointと元の版の照合を済ませてから一度行う。コピー後は同じセッションの追加コピーを受け付けず、片付け失敗でも自動で繰り返さない。元の版が変わった場合は古い本文を無言で使用せず、入力を独立した文章として救出できるようにする。

## 完成文を残す場合

同じ相手・用件へ繰り返し使う場合だけ、完成文の名前を確認して別UUIDの固定文として保存する。名前は任意で、未入力なら本文から表示名を作る。元のひな型名は`originTitle`のsnapshotで、更新・削除に追随する参照ではない。ひな型と完成文の関係を、現在の値が常に最新であるという意味にしない。競合時の独立救出は通常の新規文章として保存し、由来名の保持を保証しない。

保存した固定文をピン留めすればKeyboardの候補にできる。毎回変わる値を使う人へ、固定文の増殖や命名・整理を強制しない。準備作業の回復は別に成立させる。

## Keyboardを担当から外す理由

Keyboard内部のUITextFieldをfirst responderにしただけではOS標準の日本語キーが現れず、OSの次のキーボードへ切り替えると入力が外部欄へ向かった試作観測がある。条件と証拠例は[設計根拠](../design/evidence.md#r04-keyboard内部の標準入力試作)に置く。これを独自IME一般の不可能性へ広げない。

Keyboardはピン留め固定文だけを扱う。検索・差し替えは本体へ戻り、完成文をコピーして入力先でペーストする。狭い領域の独自IMEを保守する費用は採用せず、アプリ往復が増える負担を一連の利用で評価する。

## 検証

既定オフのMustache/コード原文、指定だけを変えた作業のcheckpoint・再開・保存、固定文からひな型への変更と戻し、同名の複数印、無効な印、改行・Unicode、値不足、日本語変換中の確定拒否、値入力・全文確認中の中断、元の版の更新・削除、コピー連打、コピー後の片付け失敗を確認する。任意保存後の本文と由来名が、ひな型更新に追随しないことも確認する。手順と結果は[実行検証](../ios-verification.md)へ集約する。
