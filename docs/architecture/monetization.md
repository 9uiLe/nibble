# 収益と機能アクセス

現行の製品構成に、課金、Pro権利、広告、外部analyticsを持たない。文章の作成・検索・編集・差し替え・コピー・固定文挿入を、購入状態の判定へ接続しない。

既存の商品登録や将来計画は、製品へ機能制限、購入画面、広告枠、権利の共有保存を追加する根拠にしない。継続価値への寄与と、入力・確認・利用・回復への負担を一連の利用で示せる場合に、別の設計判断として扱う。

## 採用しない責務

本体のStoreKit監視、拡張向け権利snapshot、広告SDK・配信枠、同意状態、使用回数の収益分析を製品経路へ残さない。本文・検索語・準備値を課金・広告・analyticsへ送らない。

App Store Connect上の登録や配布設定は、アプリが購入機能を提供する証拠ではない。配布の権限と秘密情報の規約は[TestFlight手順](../testflight.md)に従う。

## 見直し条件

採用する場合は、利用者が得る継続的な価値、料金と権利、失効時の文章と作業の保持、権限・プライバシー、運用と保守をまとめて比較する。保存済み文章や作業の損失を収益上の誘導に使わない。現行仕様は[製品仕様](../product-specification.md)が正本である。
