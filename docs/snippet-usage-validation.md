## 保存層と操作モデルの性能

同じiOS Simulatorで、変更前`db50cea90ad3e4736af7372cb87d9f814dec1fe4`と変更後`c2f82408f2c724bdd22470c154d47717b27be6b2`の製品モデル・保存層の原本をApple Swift `-Osize`でコンパイルした独立harnessを実行した。クリップボードと読み上げだけは記録用effectへ置換し、製品の取得・コピー・永続化コードは変更していない。

保存済み10,000件、ピン200件、短文64 bytesと長文620,000 bytes。同じschema 1 seedから各プロセスを開始し、変更後は製品のmigrationでschema 2に移行した。各操作5回のwarmup後に100回、各版3プロセス、base→final→final→base→base→finalの順で計測した。集計は各操作300回の中央値とnearest-rank p95。コピーは両版とも`LibraryModel.copy`を直接awaitし、変更後だけが使用記録と一覧再取得を含む。

| 操作 | 変更前 中央値 / p95 | 変更後 中央値 / p95 |
| --- | --- | --- |
| 10,000件から100件を一覧取得 | 0.252 / 0.334 ms | 0.270 / 0.359 ms |
| 短文コピー操作 | 0.013 / 0.021 ms | 0.407 / 0.562 ms |
| 長文コピー操作 | 0.212 / 0.262 ms | 1.760 / 2.146 ms |

プロセス最大RSSは変更前66.49–66.50 MB、変更後69.63–69.66 MB。使用記録と再取得の追加によりコピー時間とメモリは増えている。実測はSimulatorのモデル・SQLite処理であり、OSクリップボード、画面描画、実機応答の測定値ではない。記録は`artifacts/usage-performance/run-20260919T072821Z/`のソースhash・コンパイル条件・全標本・実行ログで照合する。

## 画面操作とスクロール

画面操作は`b3ec06ab657163b21e6ee2f874bbcb1e6f385d14`をビルドした`20260919T074855Z-usage-ui-27a66c`で実施した。変更前の画面はmainと同じ製品ソースの`1cc77350ca7f17cd19247bf96ec42bed4fa01cc1`を使った`20260919T071822Z-usage-before-2ea2da`。各runは入力hash、Apple CLIの終了コード、媒体hashを保持する。データは専用Simulatorのダミーで、終了時に元のデータを復元した。

- 「すべて」の全体順、ピン留めされた整理候補、一覧コピー後の候補解除と並べ替え、削除取り消し、検索からの同じUUIDへの集計、再起動後の保持を確認した。
- 4回のコピーで使用回数が2から6、確定receiptが4件となった。クリップボードの結合文字・絵文字を含むUTF-8本文を照合した。
- SQLiteの書込を意図的に失敗させ、コピー済みの表示と使用記録だけの再試行を確認した。障害を除去した再試行で1回分だけ記録され、表示が復帰した。
- 375×667ptでライト・ダーク、端末の最大文字サイズ設定に対する製品の固定表示、ピン留め0件の案内を確認した。意味情報はAccessibility treeで確認し、実際のVoiceOver読み上げは行っていない。
- 録画は抽出フレームによる確認であり、連続再生やフレーム時間の計測ではない。

## 実行時の失敗と測定の限界

初期のUI driver実行3件は、6秒の取り消し期限を超えた操作、再起動後のシステムタブの識別子の不一致、編集メニューからの貼り付け失敗により中断した。これらを合格証跡に含めず、操作方法を修正した独立runで同じ製品ソースを再検証した。

SimulatorはAnimation HitchesとSwiftUIのInstruments templateを受け付けず、Time Profilerの接続も完了しなかった。CPU時間の測定で代替した範囲だけを報告し、FPS・hitch時間・GPU負荷を検証済みとして扱わない。

## 範囲と制約

OSへのクリップボード書込呼出しの戻りをコピー完了とする。OS書込とSQLiteは別の確定処理であり、両者の間のプロセス終了による使用記録の喪失は防げない。確定済みの使用情報は再起動後も保持し、未確定記録の再試行待ちはプロセス内だけで保持する。実機、iOS 26.0、VoiceOverの実読み上げは本記録の実施範囲に含めない。
